# AOP v0.5 Compliance Badge

Add this to your project's README to declare AOP v0.5 compliance:

```markdown
[![AOP v0.5 Compliant](https://img.shields.io/badge/AOP-v0.5%20compliant-blue?style=flat-square)](https://agentoperationprotocol.org/v0.5)
```

Renders as:

[![AOP v0.5 Compliant](https://img.shields.io/badge/AOP-v0.5%20compliant-blue?style=flat-square)](https://agentoperationprotocol.org/v0.5)

## What compliance means

By displaying this badge, you assert that your system:

- Enforces all six AOP laws at its API boundary
- Returns structured rejection responses per AOP rejection semantics
- Records governance rejections in an audit log
- Does not weaken the six core laws through extensions

See [spec.md](./spec.md) for the full compliance definition.
